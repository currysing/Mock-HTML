申請數碼企業身份 (CorpID)
CorpID 帳户註冊的條款及細則（適用於企業）
本條款及細則（「條款」）管轄您使用數碼企業身份（CorpID）服務（「服務」）的相關事宜。請在申請 CorpID 帳戶前仔細閱讀本條款。申請 CorpID 帳戶即表示您同意受本條款約束。
1. 定義
「CorpID」指由香港特別行政區政府提供的數碼企業身份識別系統，旨在讓企業能夠安全地進行身份驗證及使用各類政府及商業服務。「帳戶持有人」指在本服務下註冊帳戶的企業法人實體。「授權代表」指獲帳戶持有人授權使用 CorpID 帳戶的個人。
2. 申請資格
申請人須為在香港依法成立的法人實體，包括有限公司、合夥企業及其他商業組織。申請人須提供真實、準確及完整的資料，並於資料有所變更時及時更新相關資料。每個法人實體只可申請一個 CorpID 帳戶。
3. 身份驗證
申請人的授權代表須通過本服務指定的身份驗證程序，包括使用智方便（iAM Smart）或其他認可的電子身份認證方式進行個人身份核實。企業身份則需通過公司登記資料核對及相關文件審查。身份驗證程序可能需時數個工作天。
4. 數碼憑證及私隱保護
CorpID 帳戶使用業界標準的數碼憑證技術保護您的企業身份及交易安全。您有責任妥善保管您的帳戶登入憑據及相關私鑰，並防止未經授權的第三方獲取。如發現帳戶被盜用或憑證洩露，您須立即通知本服務管理機構。本服務收集的個人資料將按照《個人資料（私隱）條例》（香港法例第486章）妥善處理。
5. 系統要求及可用性
使用本服務須符合指定的技術要求，包括相容的網頁瀏覽器、操作系統及網絡連線。本服務管理機構將盡力維持服務的持續可用性，但不保證服務不會中斷。定期系統維護可能導致服務暫時停用，相關通知將提前發佈。
6. API 服務及第三方整合
CorpID 提供應用程式介面（API），允許授權的第三方服務供應商與本系統整合。使用 API 服務須另行申請並遵守相關技術規範及使用協議。本服務管理機構保留隨時修改或終止 API 服務的權利。
7. 帳戶管理及終止
帳戶持有人有責任確保帳戶資料的準確性及及時更新授權代表名單。本服務管理機構保留在帳戶持有人違反本條款時暫停或終止其帳戶的權利。帳戶終止後，相關數碼憑證將同時失效。企業如已解散或停業，須通知本服務管理機構並申請終止帳戶。
